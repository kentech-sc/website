# Third-party references

## KENTECHTIME

The timetable and graduation-requirement features were designed with reference to
[EFAI-Team10/KENTECHTIME](https://github.com/EFAI-Team10/KENTECHTIME), with permission from its authors.

This project reimplements the selected behavior in SvelteKit and integrates it with this application's
existing authentication, authorization, data model, and visual system. It does not include KENTECHTIME's
AI or automatic timetable recommendation features.
